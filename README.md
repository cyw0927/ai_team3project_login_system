# AX 수강생 평가 · 자동 팀 편성 시스템

Django 기반의 **수강생 평가, 결과 관리, 자동 팀 편성, 역량 성장 관리** 통합 프로젝트입니다.

이 프로젝트의 핵심은 단순 점수 기록이 아니라 다음 흐름을 하나로 연결하는 것입니다.

```text
수강생 등록
→ 평가 회차·기본 과제 운영
→ 팀/개인 평가
→ 결과·순위 계산
→ 튜터 보정 및 공개
→ 누적 Seed 계산
→ 다음 회차 자동 팀 편성
→ 공통 역량 및 개별 성장 과제 관리
```

---

## 1. 주요 기능

### 수강생 관리

- 수강생 등록·수정·비활성화·삭제
- Excel 일괄 등록/내보내기
- 이메일은 선택 입력
- 이메일 없이 이름만으로 관리용 수강생 등록 가능
- 이메일이 없는 계정은 내부 username을 자동 생성
- 비밀번호가 없으면 로그인 불가 관리용 계정으로 생성
- 수강생별 평가 결과, 배지, 역량 프로필, 관리자 피드백 확인

### 평가 회차와 기본 과제

- 평가 회차 생성 및 현재 회차 지정
- 시작 전 / 진행 중 / 종료 상태 관리
- 평가 시작·중단·재개
- 팀 과제 / 개별 과제 등록
- 과제 첨부파일
- 팀·개인 제출 관리
- 평가 템플릿 재사용
- 발표 당일 출결에 따른 평가 권한 처리

### 팀·개인 평가

핵심 비즈니스 규칙은 `docs/templates/01_requirements/`의 BR-01 ~ BR-10을 기준으로 합니다.

주요 규칙:

- 자신의 팀은 팀 평가할 수 없음
- 다른 팀 구성원은 개인 평가할 수 없음
- 같은 팀 구성원은 개인 평가 가능
- 자기 자신은 개인 평가할 수 없음
- 동일 평가자의 동일 대상 중복 평가 금지
- 팀 점수는 다른 팀에게 받은 평가 기반
- 개인 점수는 같은 팀 구성원에게 받은 평가 기반
- 기본 최종점수는 팀 40% + 개인 60%
- 결과는 다음 회차 자동 팀 편성 Seed에 반영

### 결과·순위·관리자 보정

- 팀점수 / 개인점수 / 최종점수 계산
- 순위 계산 및 결과 공개 설정
- 관리자 보정점수 입력 가능
- 보정점수 자체 범위 제한 없음
- 0이 아닌 보정값에는 사유 필수
- 원 평가점수와 관리자 보정값은 별도 보존
- Excel 결과 내보내기
- 평가 패턴 점검

### 배지

현재 배지는 세 종류입니다.

- **MVP**: 현재 회차 최종 1위
- **성장왕**: 이전 회차 대비 순위 상승폭이 가장 큰 수강생
- **연속 우수**: 이전·현재 회차 모두 상위 3위

회차에 연결된 역량 과제가 완료된 경우 배지 산정용 점수에 해당 성과가 반영될 수 있습니다.

## 2. 역량 성장 관리

### 공통 역량 설정

관리자가 `Python`, `SQL`, `데이터 분석`, `발표`, `협업` 같은 공통 역량을 한 번 정의합니다.

- 새 공통 역량 생성 시 활성 수강생 전체에 자동 적용
- **초기 점수는 모두 0점**
- 새 수강생 등록 시 기존 공통 역량을 자동 생성
- Excel 신규 등록에도 동일하게 적용
- 누락된 역량은 관리자 화면에서 일괄 동기화 가능
- 기초 역량이 있는 수강생은 튜터가 개별 점수를 직접 수정 가능
- 기본 과제나 성장 과제에서 사용 중인 역량은 실수로 삭제되지 않도록 보호

### 기본 과제 → 역량 반영

회차의 기본 과제에도 필요한 역량과 가중치를 지정할 수 있습니다.

예:

```text
데이터 분석 과제
Python       40%
SQL          30%
데이터 분석   30%
```

역량 가중치 합계는 100%입니다.

회차가 종료되고 평가 결과가 계산되면 해당 기본 과제의 성과가 수강생 역량 프로필에 반영됩니다.

기본 평가가 1~5점 체계이므로 내부 반영 시 100점 기준으로 환산합니다.

### 개별 역량 과제

기본 과제와 별도로 특정 수강생에게 **추가 성장 과제**를 줄 수 있습니다.

관리자는 다음 항목을 설정할 수 있습니다.

- 과제명
- 담당 수강생
- 설명
- 시작일 / 마감일
- 상태 / 우선순위
- 연결 평가 회차
- 필요 역량 및 가중치
- 관리자 첨부파일
- 수행 단계와 단계별 상세 지시사항

관리자가 첨부한 가이드·예시 파일은 해당 수강생이 과제 화면에서 직접 받을 수 있습니다.

### 수행 단계와 제출

수행 단계는 **학생의 자기진도 체크**입니다.

```text
단계 확인
→ 학생이 자기진도 체크
→ 결과물 제출
→ 관리자 검토
→ 관리자 0~100점 평가
→ 최종 완료
→ 역량 점수 반영
```

학생이 단계에 체크했다고 과제가 완료되거나 점수가 확정되지는 않습니다.
최종 완료는 제출물을 튜터가 평가한 뒤 확정됩니다.

각 단계에는 최대 3,000자의 상세 지시사항을 입력할 수 있습니다.

### 역량 점수 업데이트

기본 과제와 개별 역량 과제 모두 역량 성장에 반영할 수 있습니다.

현재 성장 과제의 기본 반영 개념은 다음과 같습니다.

```text
새 점수 = 기존 점수
        + (과제 평가점수 - 기존 점수)
        × 역량 가중치
        × 반영 계수
```

공통 역량이 누락되어 자동 생성되는 경우에도 시작점은 0점입니다.
관리자는 필요하면 수강생 상세 화면에서 점수를 직접 보정할 수 있습니다.

## 3. 관리자 화면

### 관리자 홈

현재 운영 상태와 즉시 처리해야 할 항목을 한 화면에서 확인합니다.

- 현재 평가 회차
- 수강생 / 팀 / 평가 완료율
- 운영 Action Center
- 기본 과제 현황
- **역량 과제 요약**
  - 진행 중
  - 검토 요청
  - 지연
  - 예정
- 확인이 필요한 역량 과제 최대 5개
- 항목 클릭 시 해당 과제로 직접 이동

### 성장 대시보드

- 전체 역량 과제 현황
- 검토 대기
- 지연 과제
- 평균 자기진도
- 수강생별 역량 평균
- 최근 과제 평가
- 진행 중 과제
- 모든 과제 항목에서 해당 과제로 직접 이동

### 사이드바 알림

`역량 과제 관리` 메뉴에는 관리자가 확인해야 하는 과제 수가 배지로 표시됩니다.

알림 대상:

- 검토 요청
- 마감 지연

하나의 과제가 두 조건에 모두 해당해도 1건으로 계산합니다.
0건이면 배지는 표시하지 않습니다.

## 6. 설치

### 1) 가상환경

Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

PowerShell 실행 정책 때문에 활성화가 막히면 현재 터미널에서만 다음을 사용할 수 있습니다.

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

### 2) 패키지 설치

```powershell
pip install -r requirements.txt
```

주요 의존성:

- Django
- django-allauth
- python-dotenv
- psycopg
- openpyxl

### 3) 환경변수

`.env.example`을 참고해 `.env`를 설정합니다.

필수 PostgreSQL 항목:

```env
DB_NAME=postgres
DB_USER=postgres
DB_PASSWORD=...
DB_HOST=127.0.0.1
DB_PORT=5432
DB_SCHEMA=practice
```

프로젝트는 `practice, public` 순서의 PostgreSQL `search_path` 사용을 전제로 합니다.

OAuth를 사용할 경우 Google/Kakao 키도 `.env`에 설정합니다.

> `.env`에는 실제 비밀번호와 OAuth Secret이 들어갈 수 있으므로 Git에 커밋하지 마세요. `.gitignore`에서 제외되어 있습니다.

## 7. DB 준비와 실행

처음 구성하는 경우:

```powershell
python manage.py prepare_postgres
python manage.py migrate
python manage.py check
```

개발 서버 실행:

```powershell
python manage.py runserver
```

같은 네트워크의 다른 기기에서도 접속하려면:

```powershell
python manage.py runserver 0.0.0.0:8000
```

기본 로컬 주소:

```text
http://127.0.0.1:8000/
```

관리자 화면:

```text
http://127.0.0.1:8000/management/
```

## 8. 현재 필요한 Migration

현재 migration은 `0032`까지 포함합니다.

최근 주요 변경:

- `0030` 관리자 보정점수 저장 범위 확장
- `0031` 기본 과제 역량 연결 / 역량 반영 이력 / 성장 과제 첨부파일
- `0032` 성장 과제 Step 상세 지시사항

프로젝트를 갱신한 뒤에는 다음만 실행하면 됩니다.

```powershell
python manage.py migrate
python manage.py check
```

## 9. 파일 및 데이터 관리

### media 폴더

`media/`는 과제·제출물 등 실제 업로드 파일을 보관합니다.

관리자 데이터 관리 화면에서 **DB가 참조하지 않는 orphan 파일만** 정리할 수 있습니다.
현재 DB에서 사용하는 다음 파일은 자동 정리 대상에서 보호됩니다.

- 기본 과제 첨부파일
- 팀 제출 첨부파일
- 개인 제출 첨부파일
- 역량 과제 관리자 첨부파일
- 역량 과제 학생 제출 첨부파일

### 역량 과제 삭제

역량 과제를 삭제하면 다음 연결 데이터도 함께 정리합니다.

- Step
- 필요 역량
- 제출 기록
- 평가 기록
- 역량 반영 이력
- 관리자 첨부파일
- 학생 제출 첨부파일

이미 역량에 반영된 해당 과제의 점수 변화량도 취소합니다.

## 요약

이 프로젝트는 **평가 → 결과 → 자동 팀 편성**을 중심으로 하고, 그 위에 **공통 역량 → 기본 과제 성장 반영 → 개별 역량 과제 → 튜터 평가 → 역량 프로필 누적**을 연결한 수강생 운영 시스템입니다.

관리자는 한 화면에서 운영 상태와 확인할 과제를 파악하고, 수강생은 자신의 평가·과제·성장 상태를 확인할 수 있도록 구성되어 있습니다.
