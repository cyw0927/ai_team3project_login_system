# 프로젝트 문서

문서는 두 영역만 유지합니다.

## `templates/`

프로젝트 최초 요구사항과 설계 기준입니다.

- `01_requirements/` — BR-01 ~ BR-10, 요구사항 추적
- `02_data/` — ERD, 테이블 정의
- `03_programs/` — 프로그램·권한 정의
- `04_scenarios/` — 사용자 흐름과 상세 시나리오
- `05_ui/` — UI 명세
- `06_test/` — 테스트 기준
- `07_project/` — Epic / Issue / Review 기준

## `guides/`

현재 프로젝트를 실행하거나 설정할 때 필요한 문서입니다.

- `LOCAL_RUN_GUIDE.md`
- `POSTGRESQL_SETUP.md`
- `OAUTH_SETUP.md`
- `PROJECT_STRUCTURE.md`
- `VIEW_STRUCTURE.md`

프로젝트 전체 기능과 최신 실행 방법은 **루트 `README.md`를 먼저 확인**하세요.
