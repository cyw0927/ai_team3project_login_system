# AX 평가 시스템 - 팀원 실사용 테스트 가이드

이 문서는 실제 팀원들이 각자 로그인해서 한 회차를 처음부터 끝까지 테스트할 때 사용하는 체크리스트입니다.

## 1. 테스트 전 관리자 준비

1. PostgreSQL과 `.env` 설정 확인
2. migration 적용
   ```powershell
   python manage.py migrate
   ```
3. 관리자 계정 확인
4. 카카오/Google OAuth를 사용할 경우 `python manage.py check_login_setup` 실행
5. 같은 Wi-Fi에서 테스트하면 서버 실행
   ```powershell
   python manage.py runserver 0.0.0.0:8000
   ```

## 2. 권장 테스트 데이터

실제 팀원은 카카오/Google 또는 본인 계정으로 로그인하는 것을 우선 권장합니다. 자동 평가용 더미 계정은 실제 팀원 계정과 구분해 사용합니다.

- 실제 사용자: 각 팀원 본인 계정
- 자동 평가용: `student01`, `student02`처럼 `studentNN` 형식
- 관리자: superuser 계정

더미 계정은 실사용 테스트가 끝난 뒤 `delete_dummy_students`로 제거할 수 있습니다.

아래 순서대로 한 번 완주합니다.

- [ ] 수강생이 정상 등록/로그인됨
- [ ] 회차 생성
- [ ] 팀 편성
- [ ] 각 팀원의 역할 입력
- [ ] 조별과제 생성
- [ ] 개별과제 생성
- [ ] 팀/개인 평가 템플릿 생성 및 회차 적용
- [ ] 회차 시작
- [ ] 평가 시작
- [ ] 평가 중단 후 학생 화면에서 입력이 막히는지 확인
- [ ] 평가 재개 후 다시 입력 가능한지 확인
- [ ] 평가 종료
- [ ] 결과 계산 확인
- [ ] 관리자→학생 개인 피드백 작성
- [ ] 결과 공개

## 4. 학생별 테스트 시나리오

### 홈 / 팀
- [ ] 학생 홈에 현재 회차가 정상 표시됨
- [ ] 종료 회차는 회색 계열로 표시됨
- [ ] 팀원 이름/이메일/소속/역할이 정상 표시됨

### 과제
- [ ] 조별과제는 같은 팀에서 제출물이 하나만 유지됨
- [ ] 다른 팀원이 들어가도 같은 조별 제출물을 조회함
- [ ] 개별과제는 학생별로 따로 제출됨
- [ ] 링크/첨부/메모 저장과 수정이 정상 동작함
- [ ] 평가 시작 후 과제 수정 제한이 의도대로 동작함

### 평가
- [ ] 자기 팀을 팀 평가할 수 없음
- [ ] 다른 팀원 개인평가가 노출되지 않음
- [ ] 같은 팀원만 개인평가 가능
- [ ] 자기 자신은 개인평가 불가
- [ ] 같은 대상을 중복 최종제출할 수 없음
- [ ] 코멘트 작성/수정이 정상 동작함

### 결과 / 피드백
- [ ] 결과 비공개 상태에서는 점수가 보이지 않음
- [ ] 공개 후 팀/개인/최종점수가 정상 표시됨
- [ ] 레이더 차트가 평가 문항별 점수를 표시함
- [ ] 동료 코멘트가 정상 표시됨
- [ ] 관리자 개인 피드백이 정상 표시됨

### 프로젝트 회고
- [ ] 종료된 참여 회차만 선택 가능
- [ ] 만족도/기여도/협업/난이도 및 회고 텍스트 저장 가능
- [ ] 다시 저장하면 기존 회고가 수정됨
- [ ] 회고 점수가 성적에 섞이지 않음

## 5. 자동 랜덤 평가가 필요한 경우

사람이 직접 입력하지 않을 더미 학생 평가만 생성합니다.

```powershell
python manage.py seed_random_evaluations --min-score 2 --max-score 5
```

실제 사용자가 이미 제출한 평가는 덮어쓰지 않습니다.

자동 생성 평가만 삭제하려면:

```powershell
python manage.py delete_random_evaluations
```

더미 학생 자체를 삭제하려면:

```powershell
python manage.py delete_dummy_students
```

## 6. 테스트 중 기록할 것

오류가 발생하면 아래 5가지를 같이 남깁니다.

1. 사용 계정
2. 관리자/학생 여부
3. 회차 이름
4. 누른 버튼과 직전 행동
5. 브라우저 화면 + 서버 터미널 traceback

화면 문제는 화면 전체 캡처를 남기고, 기능 오류는 반드시 서버 터미널 오류까지 같이 남기면 원인 파악이 빠릅니다.

```powershell
python manage.py makemigrations --check --dry-run
python manage.py test dashboard
```

모두 통과한 뒤 Git 상태를 확인합니다.

```powershell

git diff --check
git add -A
git diff --cached --check
```

`.env`, `media/`, `.venv/`, `__pycache__/`가 커밋에 포함되지 않았는지 반드시 확인합니다.
